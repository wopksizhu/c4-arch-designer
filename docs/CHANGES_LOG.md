# ArchLens 改动日志

> 本文档记录每次对 ArchLens 的修改，用于**多台电脑同步**协作。每次改动请：
> 1. 在本文件顶部「最新」一行简要写明 日期 + 改了什么；
> 2. `git add -A && git commit -m "<说明>"`；
> 3. `git push`（多台电脑见文末「同步操作」）。

## 最新

### 2026-xx-xx 框体半透明 + 连线数据流小光点
- **框体半透明**：节点背景改 `rgba(13,11,19,.74)` + 微模糊，被框体遮住的连线能**透出**看到。
- **连线数据流标识**（替代/辅助箭头）：每条线有一个**沿曲线流动的小光点**（SVG `animateMotion` 从源→目标流动），直观表示数据流向；hover/选中时光点更大更亮、线加粗。
- 相关：`web/src/index.css`（`.c4-neon` 半透明）、`web/src/components/C4Canvas.tsx`（流动光点 circle + animateMotion）。
- **连线标签默认隐藏**：整体界面更干净。
- **hover 边**：加粗(3px) + 显示标签（消息名）。
- **点击边**：加粗选中；**点空白**取消选中。
- **默认线更细（1.3px）**：比框体外边框更细，不再粗重。
- 霓虹边加**宽命中区**（透明 interaction path），细线也便于 hover/点击。
- 相关：`web/src/components/C4Canvas.tsx`；新增 E2E「连线默认无标签/hover 显示/点空白取消」。
- 连线箭头从**生硬三角**改为**弧线燕尾箭头**（`C` 贝塞尔构成、凹背），从曲线平滑延展出去，贴合线本身的弧度。
- 箭头仍固定小尺寸（`userSpaceOnUse`），多线不杂乱。
- 相关：`web/src/components/C4Canvas.tsx`（`marker` 路径改为弧形）。
- 并行（同向）连线恢复**温和弧线**（曲率 0.2），不再是僵硬直线，多条线成柔和的环状弧、更耐看。
- **箭头改小**：自定义 line 箭头用 `userSpaceOnUse` 固定小尺寸（约 9px，不再随线宽放大），多线时不再显得杂乱。
- 相关：`web/src/components/C4Canvas.tsx`。
- 新增 **`web/e2e/edge-layout.spec.ts`**：自动创建多种连线场景（1 条 / 同向并行 3/6 条 / 双向 / 4同向+2反向混合），并**自动断言**「主边数量正确、各边起点两两不同（分散、不重叠）」——以后改布线不用逐个手点，跑这个测试即可自动验证。
- 运行：`cd web && npx playwright test edge-layout.spec.ts`（需先启动服务）。
- 新增场景可照 `mkProject/elm/rel` 在本文件里扩展。
- 相关：`web/e2e/edge-layout.spec.ts`。（后端 `arc` 仅反向边、前端有向组等距铺开，见上一条。）
- **多条连线不再重叠**：
  - **正向(A→B)** 多条：走**直的**，端点按有向组内**等距铺开**（0.16–0.84），成平行直线。
  - **反向(B→A)**（双向边）：绕到**另一侧**（水平→下边、垂直→左边），避开正向直线。
- 同一对框体画任意多条线都能铺开，不挤在一起。
- 相关：`web/src/lib/edges.ts`（仅反向边 arc）、`web/src/components/C4Canvas.tsx`（有向组等距铺开 + 反向按轴绕另一侧）。
- 双向边 (A↔B) 的绕开方向现在**按框体相对轴**选择：**水平排布**走上/下边；**垂直堆叠**走**左/右边**（一左一右），不再绕框打圈、不交叉。
- 相关：`web/src/components/C4Canvas.tsx`（按 `dx/dy` 判轴、arc 定边）。
- **双向边 (A↔B) 布线协调**：之前两条双向边都用「底→顶」弧形导致中间交叉成 X。现改为 **A→B 走上边(top)、B→A 走下边(bottom)**，一条在上、一条在下，不交叉。
- 同向并行边保持平行直线（端点错开）；双向边用上/下弧形。两类布线都协调。
- 相关：`web/src/lib/edges.ts`（`arcDir` 上/下）、`web/src/components/C4Canvas.tsx`（按 `arcDir` 定边、双向边不错开）。
- **修复图标遮挡文字**：框体右上角小图标不再压住标题——文本区右侧预留 `36px`（`padding-right`），标题过长自动省略号。
- **并行连线协调（关键）**：`arc`（底部→顶部弧形绕开）只用于**双向边**（A↔B）；**同向并行边**改用**端点沿边错开**，两条线为干净平行的直线，不再下弯/打圈。
- 并行线曲率进一步压低（0.05），更平顺。
- 相关：`web/src/lib/edges.ts`（arc 判定）、`web/src/components/C4Canvas.tsx`（曲率/错开）、`web/src/index.css`（`.c4-neon-body` 预留右侧）。
- **返回箭头**：霓虹边（普通渐变与特殊实心）都加**方向箭头**，连接方向更清晰。
- **只有图标可拖动**：把「展开/添加子元素」文字按钮改为**框体右上角小图标**（▸ 展开 / ＋ 添加），按钮所在操作栏 `nodrag`——拖动框体只有抓**图标块**才生效，其它地方用于连线。
- **选中高亮 + 点击空白取消**：选中框体出现紫色高亮描边；点空白取消选中。
- **展开父框更美观**：暗色半透明底 + 细霓虹描边 + 更清晰标题。
- **子元素四边留白对称**：父框左右/上下的内边距一致（`CHILD_MIN_X=50`、`CHILD_MIN_Y=58`、`PAD=50`），新增子元素时右下不再比左上更大。
- **并行连线更平顺**：去掉过大的交替曲率（避免“loop”），用更温和曲率 + 端点沿边错开，多条线自然散开。
- 相关：`web/src/components/C4Canvas.tsx`、`web/src/index.css`、`web/src/lib/geometry.ts`、`web/src/pages/ModelPage.tsx`。
- **只保留霓虹**：去掉浅色主题与「霓虹」切换按钮（`theme` 恒为 neon）。
- **框体固定宽度**（230px）：标题/类别/描述过长时用**省略号**截断。
- **交互更舒适**：只有**图标块可拖动框体**（grab 光标 + z-index 提升），框体其它任意处都能**拉出连线**（crosshair）；点击框体选中、按钮可点。
- **特殊边保持实心色**：缺失(红)/循环(橙)/选中(蓝)在霓虹下用**实心描边**（不加渐变），普通边才用源→目标渐变。
- 相关：`web/src/components/C4Canvas.tsx`、`web/src/pages/ModelPage.tsx`、`web/src/index.css`、`web/e2e/model.spec.ts`。
- **连线端点完全自适应**：每一条线按其「源→目标」相对方向，在源/目标框体边界上求出独立的进/出点（`computeExit` 求边界交点+比例），不再固定到 4 个点。
- **同一对框体的多条线各自独立、分散**：`pairFan` 给每条线 `fanIndex/count`，沿边错开锚点比例并交替曲率，多条线一上一下散开、不重叠。
- **压平曲率**：`getBezierPath` 传入自适应 `curvature`（普通 0.18 / 弧形 0.3 / 并行 0.22/0.42），消除线“翘起来”的问题。
- **框体自由连线**：抓住节点框体空白拖到另一个框体即建连（自定义连接系统 `elementFromPoint` 命中 + 临时连线预览）；标题=拖动节点、点框体=选中、按钮可点。
- **去固定端点**：节点不再显示 4 个固定连接点（句柄隐藏），连线直接从框体边界流出。
- 相关：`web/src/components/C4Canvas.tsx`、`web/src/index.css`。

## 同步操作（多台电脑）
1. **本机克隆**：`git clone https://github.com/<你的用户名>/<仓库名>.git`（如已在用：`git pull` 先同步）。
2. **改完**：`git add -A && git commit -m "说明" && git push`。
3. **换电脑**：`git pull`。
4. **每次改动**：在本文件顶部加一条「日期 + 改了什么」，随代码一起提交。

> 注意：`data/`（SQLite 数据）、`node_modules/`、`dist/`、`archlens.exe`、`web/playwright-report`、`web/test-results` 均不入库（见 `.gitignore`），各电脑各自生成。
