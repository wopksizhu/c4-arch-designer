# ArchLens 画布功能完善清单（对标 IcePanel）

> 本文是画布功能待办清单。每条含「编号 / 功能 / 说明 / 优先级 / 状态」。
> 开发按优先级从 P0 开始逐条实现，完成后把「状态」改成 ✅。

## 当前已有能力（不重复开发）
- C4 画布：元素展开/折叠、严格包含（子元素在父框内）、父子拖拽跟随。
- 元素：4 种类型（person/softwareSystem/container/component）、名称/描述/技术栈/标签/层级。
- 关系：多消息、每条含名称/协议/发送端/接收端、层级关联（消息→容器/叶子）、缺失标红、箭头、双向边弧形分开、折叠聚合、堆叠标签。
- 布局：分层自动布局(Sugiyama)、展开最小化布局、元素结构树。
- 导出：Structurizr DSL / JSON / Markdown / HTML；导入 DSL。
- 需求/原型/追溯矩阵/影响分析/AI 生成与校验。

## 建议开发顺序
1. **P0-1（分类画板）** → 因为它是「添加元素」入口，后续类别/图标都挂在它上面。
2. **P0-4 / P0-5（技术栈+类别字段）** → 作为元素的元数据基础。
3. **P0-2 / P0-3（交互/协议预设）** → 表单小改，见效快。
4. **P1-1 / P1-2（图标+配色）** → 视觉提升最大。
5. 之后按 P1/P2/P3 逐条推进。

> 每条开发时：新增/修改 → 同步 `docs/TESTING.md` 登记（F 编号）→ 补后端 API 测试（如需）与 E2E。
